# Design — PromptOps Academy

Este arquivo apresenta as principais referências visuais desenvolvidas para o projeto PromptOps Academy.

As imagens servem para documentar a proposta visual da interface e facilitar a compreensão de como o sistema foi planejado antes e durante o desenvolvimento.

## Estados da Interface

Esta imagem apresenta diferentes estados que podem aparecer durante o uso do sistema.

São demonstrados os estados de:

- Estado vazio, quando não existem resultados;
- Estado de erro, quando ocorre algum problema no carregamento;
- Estado de sucesso, quando uma ação é concluída corretamente.

Esses estados servem para definir como o sistema deve informar o usuário sobre diferentes situações durante a utilização.

## Exemplos de Elementos Visuais

Esta imagem apresenta alguns dos principais elementos visuais utilizados na interface.

São demonstrados exemplos de:

- Filtros;
- Tags;
- Botões;
- Ícones;
- Elementos de navegação e interação.

Essa referência serve para manter um padrão visual entre as diferentes telas do sistema.

## Formulário/Modal (cadastro e adição)

Esta imagem apresenta o formulário utilizado para cadastrar um novo prompt.

Nela estão representados os campos necessários para adicionar informações, como:

- Título;
- Objetivo;
- Categoria;
- Pipeline;
- Tags.

Também são apresentados os botões de cancelar e salvar.

O objetivo dessa referência é demonstrar como o processo de cadastro deve ser organizado visualmente.

## Tela principal (Desktop)

Esta imagem apresenta a tela principal do PromptOps Academy em uma resolução para desktop.

Ela demonstra a organização geral do sistema, incluindo:

- Menu lateral;
- Barra de pesquisa;
- Área de boas-vindas;
- Quantidade de prompts, categorias e pipelines;
- Filtros;
- Botão para adicionar um novo prompt;
- Cards dos prompts.

Essa tela serve como referência principal para a estrutura da interface em computadores.

## Versão mobile

Esta imagem apresenta uma adaptação inicial da interface para dispositivos móveis.

Ela demonstra como os principais elementos do sistema podem ser reorganizados em uma tela menor, mantendo as funcionalidades essenciais.

A versão mobile serve como referência para o desenvolvimento responsivo do PromptOps Academy, que ainda está em desenvolvimento no protótipo.

## Finalidade das imagens

As cinco imagens, em conjunto, representam as principais decisões visuais do projeto.

Elas servem como referência para:

- Desenvolvimento da interface;
- Implementação do layout responsivo;
- Padronização dos elementos visuais;
- Verificação da interface durante os testes;
- Comparação entre o design planejado e o sistema desenvolvido.
