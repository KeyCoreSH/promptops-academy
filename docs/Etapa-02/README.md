## Formulário de Cadastro

Esta referência apresenta a interface utilizada para cadastrar um novo prompt.

O formulário deve organizar os campos necessários para o preenchimento das informações, facilitando a compreensão e a utilização pelo usuário.

São considerados elementos como:

- Campos de texto;
- Seletores de opções;
- Campos de informações do prompt;
- Botões de ação, como salvar e cancelar.

O objetivo é manter uma organização clara e consistente, facilitando o preenchimento dos dados.

## Formulário de Edição

Esta referência apresenta a interface utilizada para editar um prompt já cadastrado.

Os campos devem permitir a alteração das informações existentes, mantendo os dados atuais disponíveis para consulta e edição.

A interface deve seguir o mesmo padrão visual do formulário de cadastro, preservando a consistência entre as telas.

## Estados do Formulário

Esta seção apresenta as referências visuais dos estados que podem ocorrer durante o preenchimento e o envio do formulário.

Podem ser representados:

- Campos obrigatórios;
- Mensagens de erro;
- Indicação de informações inválidas;
- Confirmação de cadastro ou edição concluída.

Esses estados devem ajudar o usuário a compreender o que precisa ser corrigido ou quando uma ação foi concluída.

## Finalidade das Imagens

As imagens desta etapa servem como referência para:

- Implementação da interface de cadastro e edição;
- Organização dos campos e botões;
- Padronização dos elementos visuais;
- Verificação da interface durante os testes;
- Comparação entre o design planejado e a implementação.

## Critérios de Validação do Design

- O formulário deve apresentar os campos de maneira organizada;
- Os rótulos devem permitir identificar a finalidade de cada campo;
- Os botões devem apresentar ações compreensíveis;
- Os estados de erro e sucesso devem ser claros;
- A interface de edição deve manter consistência visual com a de cadastro;
- O design deve servir como referência para a implementação no sistema.
